# Responsive Design

Use when design adaptive layouts across breakpoints and inputs.

## Procedure

1. Define breakpoints and constraints.
2. Draft adaptive layout rules.
3. Check touch and desktop flows.

## Verification

- Validate across viewports.
- No overflow or tap-target regression.
- Check content priority.
