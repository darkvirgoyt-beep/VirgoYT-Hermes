# Accessibility Engineering

Use when build inclusive ui with keyboard, screen reader, and contrast.

## Procedure

1. Audit keyboard and semantics.
2. Fix contrast and focus order.
3. Check screen reader announcements.

## Verification

- Run a11y tooling and manual checks.
- No a11y regression.
- Check WCAG level target.
