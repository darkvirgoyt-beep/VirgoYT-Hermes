# User Research

Use when plan and synthesize user interviews and usability tests.

## Procedure

1. Define research questions and recruitment.
2. Run interviews/tests.
3. Synthesize findings and priorities.

## Verification

- Report insights with evidence.
- No unsupported design assumptions.
- Check sample and bias.
