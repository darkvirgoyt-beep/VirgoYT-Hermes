# Design Review

Use when review ui designs for clarity, hierarchy, and accessibility.

## Procedure

1. Review screens and flows.
2. Check hierarchy, contrast, and copy.
3. Validate against accessibility rules.

## Verification

- Summarize issues by severity.
- No critical usability blockers.
- Check platform conventions.
