# Multi Cloud Design

Use when design workloads across cloud providers safely.

## Procedure

1. Identify provider-specific dependencies.
2. Draft abstraction and failover.
3. Check networking, identity, and data sync.

## Verification

- Validate cross-cloud failover.
- No hard provider lock-in.
- Check egress and latency.
