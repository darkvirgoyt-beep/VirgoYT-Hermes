# Low Latency Design

Use when design low-latency systems with caching and batching.

## Procedure

1. Measure p50/p99 targets.
2. Reduce critical path and sync.
3. Check caching, batching, and pooling.

## Verification

- Validate under production load.
- No latency hotspot remains.
- Check tail behavior.
