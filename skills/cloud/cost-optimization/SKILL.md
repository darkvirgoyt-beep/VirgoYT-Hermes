# Cost Optimization

Use when optimize cloud spend without breaking reliability.

## Procedure

1. Collect current spend and usage.
2. Identify idle and oversized resources.
3. Check reserved/savings plans.

## Verification

- Validate savings without SLO drop.
- No hidden reliability cost.
- Check budget alerts.
