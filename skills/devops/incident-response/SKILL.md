# Incident Response

Use when run blameless incident response and postmortems.

## Procedure

1. Detect and declare incident.
2. Triage and mitigate quickly.
3. Preserve evidence and timeline.

## Verification

- Validate recovery and monitoring.
- No unresolved action items.
- Review timeline accuracy.
