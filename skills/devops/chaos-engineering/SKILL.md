# Chaos Engineering

Use when test resilience with controlled failure injection.

## Procedure

1. Identify critical failure modes.
2. Design safe experiments.
3. Check blast radius and rollback.

## Verification

- Validate recovery behavior.
- No customer impact.
- Check experiment hygiene.
