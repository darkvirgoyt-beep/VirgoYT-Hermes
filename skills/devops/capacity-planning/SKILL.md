# Capacity Planning

Use when plan compute, storage, and concurrency headroom.

## Procedure

1. Measure current load and peaks.
2. Project growth and seasonality.
3. Check bottlenecks and tail latency.

## Verification

- Validate with load tests.
- No SLO breach under peak.
- Check cost model.
