# Huggingface Debugging

Use when debug hf models, tokenizers, and pipelines.

## Procedure

1. Read model/tokenizer error.
2. Inspect config and revisions.
3. Check cache and versions.

## Verification

- Run pipeline offline.
- No model regression.
- Check HF library version.
