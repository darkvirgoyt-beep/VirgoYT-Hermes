# Web Security

Use when harden web apps with csp, cookies, and input validation.

## Procedure

1. Audit request sources and inputs.
2. Review headers, cookies, and CSP.
3. Check XSS/CSRF protections.

## Verification

- Validate with browser security tests.
- No injection or session issue.
- Check browser compatibility.
