# Penetration Testing

Use when plan and report safe penetration tests.

## Procedure

1. Define scope and rules of engagement.
2. Enumerate targets and trust zones.
3. Run authorized tests only.

## Verification

- Report findings with evidence.
- No unauthorized access.
- Verify remediation steps.
