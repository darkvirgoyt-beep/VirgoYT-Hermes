# Threat Modeling

Use when model threats, mitigations, and trust boundaries.

## Procedure

1. Map assets and actors.
2. Identify STRIDE threats.
3. Rank risk and mitigations.

## Verification

- Validate mitigations in design.
- No unmitigated critical threats.
- Check boundary assumptions.
