# Application Security

Use when harden apps with input validation and secure defaults.

## Procedure

1. Map trust boundaries.
2. Review input handling and auth.
3. Check defaults and error handling.

## Verification

- Validate with security tests.
- No injection or auth bypass.
- Check OWASP Top 10.
