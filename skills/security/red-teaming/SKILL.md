# Red Teaming

Use when simulate adversary tactics safely and report findings.

## Procedure

1. Define scope and rules.
2. Model threat actors and goals.
3. Run controlled attacks only.

## Verification

- Report findings with evidence.
- No unauthorized access.
- Verify remediation steps.
