# Blue Teaming

Use when detect, contain, and remediate security incidents.

## Procedure

1. Monitor detection sources.
2. Investigate alerts and artifacts.
3. Contain and remediate.

## Verification

- Validate recovery and hardening.
- No persistent access remains.
- Check detection coverage.
