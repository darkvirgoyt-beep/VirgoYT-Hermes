# Api Security

Use when harden apis with auth, rate limits, and validation.

## Procedure

1. Map endpoints and trust zones.
2. Review auth, input, and rate limiting.
3. Check secrets and logging.

## Verification

- Validate with security tests.
- No auth bypass or injection.
- Check OWASP API Top 10.
