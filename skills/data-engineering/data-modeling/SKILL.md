# Data Modeling

Use when model dimensional/normalized datasets for analytics.

## Procedure

1. Define business metrics and grain.
2. Draft dimensions and facts.
3. Check keys and slowly changing dimensions.

## Verification

- Validate with query tests.
- No metric drift.
- Check lineage and ownership.
