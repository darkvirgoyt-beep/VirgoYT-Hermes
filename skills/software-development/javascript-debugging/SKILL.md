Use when debug browser/node.js runtime and async issues.

## Procedure

1. Capture console/network errors.
2. Inspect async flow and scope.
3. Check bundler/runtime mismatch.

## Verification

- Verify in target runtime.
- No regression in callers.
- Check bundler/runtime config.
