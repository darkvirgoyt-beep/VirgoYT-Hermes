# Django Debugging

Use when debug django orm, middleware, and request issues.

## Procedure

1. Read traceback and middleware chain.
2. Inspect settings and URLs.
3. Check DB/migrations/cache.

## Verification

- Run manage.py test.
- No auth/middleware regression.
- Check version compatibility.
