# Cli Design

Use when design ergonomic clis with help, errors, and piping.

## Procedure

1. Map commands and workflows.
2. Draft flags, help, and error codes.
3. Check piping and exit behavior.

## Verification

- Validate with shell scripts.
- No silent failure or bad exit code.
- Check shell compatibility.
