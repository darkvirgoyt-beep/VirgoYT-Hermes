# Api Design

Use when design rest/graphql apis with clear contracts.

## Procedure

1. List resources and operations.
2. Draft schema/contract and errors.
3. Review auth, rate limits, and versioning.

## Verification

- Validate with consumers/tests.
- Contract remains backward compatible.
- Review API docs.
