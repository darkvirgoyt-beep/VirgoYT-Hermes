# Code Review

Use when review code for correctness, security, and maintainability.

## Procedure

1. Read diff and risk areas.
2. Check logic, tests, and APIs.
3. Review security and performance.

## Verification

- Summarize findings by severity.
- No unresolved high-risk issue.
- Check regression tests.
