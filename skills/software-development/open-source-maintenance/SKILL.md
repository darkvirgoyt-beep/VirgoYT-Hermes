# Open Source Maintenance

Use when run healthy open-source projects with triage and releases.

## Procedure

1. Triage issues and PRs.
2. Set contributor and release rules.
3. Check changelog and compatibility.

## Verification

- Validate release artifacts.
- No breaking change surprise.
- Check license and security.
