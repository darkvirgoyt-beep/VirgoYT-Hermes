# Microservices Design

Use when design service boundaries, contracts, and failure modes.

## Procedure

1. Identify bounded contexts.
2. Define APIs, queues, and data ownership.
3. Review deployment and observability.

## Verification

- Validate with contract tests.
- No tight coupling introduced.
- Check SLOs and ownership.
