# Web Frontend Debugging

Use when debug react/vue/html ui faults.

## Procedure

1. Capture console/network errors.
2. Map components and state flow.
3. Inspect render boundaries and props.

## Verification

- Verify fix in browser/devtools.
- No regression in adjacent screens.
