# Blockchain Engineering

Use when design and debug blockchain apps and contracts.

## Procedure

1. Map on-chain and off-chain trust.
2. Draft contracts and events.
3. Check gas, replay, and keys.

## Verification

- Validate with testnet fork.
- No irreversible unsafe tx.
- Check upgrade controls.
