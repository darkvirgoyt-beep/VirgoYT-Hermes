# Networking Basics

Use when diagnose host/network connectivity and dns issues.

## Procedure

1. Capture ping/traceroute/dig output.
2. Inspect interfaces and routes.
3. Check firewall and DNS config.

## Verification

- Verify end-to-end connectivity.
- No firewall regression.
- Check network namespace.
