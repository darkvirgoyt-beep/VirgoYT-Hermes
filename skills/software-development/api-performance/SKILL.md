# Api Performance

Use when optimize http latency, payload, and caching.

## Procedure

1. Capture latency and payload sizes.
2. Inspect headers and caching.
3. Check batching and compression.

## Verification

- Run load test with realistic clients.
- No latency regression.
- Check cache invalidation.
