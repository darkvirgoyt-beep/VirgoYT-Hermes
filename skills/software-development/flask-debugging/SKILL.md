# Flask Debugging

Use when debug flask app context, blueprints, and extensions.

## Procedure

1. Read traceback and request context.
2. Inspect app factory and config.
3. Check extension setup and order.

## Verification

- Run pytest/flask test client.
- No blueprint regression.
- Check extension compatibility.
