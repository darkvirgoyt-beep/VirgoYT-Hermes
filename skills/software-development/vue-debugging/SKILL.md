# Vue Debugging

Use when debug vue reactivity, router, and component issues.

## Procedure

1. Capture runtime/console errors.
2. Inspect reactivity and setup.
3. Check plugin/router config.

## Verification

- Verify component behavior.
- No reactivity regression.
- Check Vue version compatibility.
