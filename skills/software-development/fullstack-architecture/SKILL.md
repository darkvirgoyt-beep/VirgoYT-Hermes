# Fullstack Architecture

Use when integrate frontend, backend, data, and infra.

## Procedure

1. Map client/server/data boundaries.
2. Draft API, storage, and auth contracts.
3. Check CORS, caching, and errors.

## Verification

- Validate end-to-end.
- No cross-layer coupling.
- Check ownership and rollout.
