# Observability Design

Use when design metrics, logs, traces, and alerting rules.

## Procedure

1. Identify critical user journeys.
2. Define SLIs/SLOs and signals.
3. Check cardinality and sampling.

## Verification

- Validate dashboards and alerts.
- No alert fatigue.
- Check retention and cost.
