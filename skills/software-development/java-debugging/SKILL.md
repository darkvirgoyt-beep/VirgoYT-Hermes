# Java Debugging

Use when debug jvm errors, classpath, and memory issues.

## Procedure

1. Read stacktrace and cause.
2. Inspect classpath and versions.
3. Check GC/memory settings.

## Verification

- Run targeted unit tests.
- No classloader regression.
- Check JDK compatibility.
