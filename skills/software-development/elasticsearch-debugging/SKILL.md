# Elasticsearch Debugging

Use when debug elasticsearch mapping, query, and cluster issues.

## Procedure

1. Read shard/allocation logs.
2. Inspect mappings and analyzers.
3. Check cluster health and settings.

## Verification

- Run cat APIs and queries.
- No mapping regression.
- Check ES version compatibility.
