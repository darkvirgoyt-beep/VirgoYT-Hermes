# Database Debugging

Use when diagnose db schema, query, and migration issues.

## Procedure

1. Identify failing query or migration.
2. Inspect schema, indexes, and relations.
3. Check ORM mappings and transactions.

## Verification

- Run migration/query plan check.
- Verify data consistency.
