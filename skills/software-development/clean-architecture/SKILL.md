# Clean Architecture

Use when organize code with entities, use cases, and adapters.

## Procedure

1. Identify business rules.
2. Separate layers and dependencies.
3. Check dependency direction.

## Verification

- Validate with tests per layer.
- No framework leakage inward.
- Check boundary contracts.
