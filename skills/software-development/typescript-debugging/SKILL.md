# Typescript Debugging

Use when debug ts types, generics, and build errors.

## Procedure

1. Read compiler errors exactly.
2. Trace generic/type inference.
3. Check tsconfig and lib settings.

## Verification

- Run typecheck and build.
- No type regression.
- Check type-level compatibility.
