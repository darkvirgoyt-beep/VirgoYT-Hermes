# Git Workflow

Use when use git safely for branches, merges, and recovery.

## Procedure

1. Read repo status and history.
2. Inspect branches and remotes.
3. Check hooks and permissions.

## Verification

- Verify status and tests.
- No history rewrite on shared branch.
- Check git version.
