# Fastapi Debugging

Use when debug fastapi routes, validation, and dependency issues.

## Procedure

1. Read OpenAPI/validation errors.
2. Inspect routers and schemas.
3. Check middleware and auth.

## Verification

- Run pytest/testclient.
- No schema regression.
- Check Pydantic v2 compatibility.
