# Testing Strategy

Use when design unit/integration/e2e test coverage.

## Procedure

1. Map critical paths and risks.
2. Choose test levels and tools.
3. Check flake and data hygiene.

## Verification

- Run targeted coverage report.
- No critical path uncovered.
- Check test reliability.
