# Agent Design

Use when design tool-using agent loops safely.

## Procedure

1. List goals, tools, and constraints.
2. Add approval gates and timeouts.
3. Implement memory and recovery.

## Verification

- Test on 10+ task variants.
- Verify no runaway loops.
