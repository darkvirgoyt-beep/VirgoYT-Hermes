Use when implement and debug transformer models and attention.

## Procedure

1. Define model shape and attention.
2. Draft layers and masking.
3. Check memory and numerical stability.

## Verification

- Validate with small synthetic batch.
- No NaN/Inf regression.
- Check implementation against paper.
