# Generative Ai Safety

Use when test generative models for safety, jailbreaks, and leakage.

## Procedure

1. Define prohibited content categories.
2. Draft test prompts and graders.
3. Check refusals and fallback behavior.

## Verification

- Validate with red-team tests.
- No unblocked harmful output.
- Check policy alignment.
