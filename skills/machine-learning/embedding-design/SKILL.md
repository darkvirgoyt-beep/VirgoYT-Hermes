# Embedding Design

Use when design text/embedding pipelines and retrieval.

## Procedure

1. Define query and corpus domains.
2. Choose model and chunking.
3. Check indexing and freshness.

## Verification

- Validate with recall tests.
- No stale index regression.
- Check dimensionality and cost.
