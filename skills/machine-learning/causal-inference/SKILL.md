# Causal Inference

Use when estimate causal effects from observational data.

## Procedure

1. Define causal question and DAG.
2. Select identification strategy.
3. Check assumptions and sensitivity.

## Verification

- Validate with placebo or simulation.
- No omitted-variable bias.
- Check model assumptions.
