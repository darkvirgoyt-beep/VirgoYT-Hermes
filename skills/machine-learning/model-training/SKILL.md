# Model Training

Use when train, validate, and checkpoint ml models safely.

## Procedure

1. Define loss and success metric.
2. Split data and configure training.
3. Check overfitting and seed.

## Verification

- Validate with held-out test.
- No data leakage.
- Check reproducibility.
